# 미션 3 기록

민수의 기획서와 영화 티어리스트를 확인하고, 직접 사용한 결과를 바탕으로 AI 검토 및 동료 피드백을 정리했습니다. 직접 테스트하지 않은 항목은 확인이 필요하다고 표시했습니다.

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI: 저장 기능이 없어 다시 열면 영화와 등급이 초기화됨 | 새로고침했을 때 영화 배치가 남지 않았음 | 반영 | 기획서에는 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남아야 한다고 되어 있음 |
| AI: ‘처음으로’를 눌러도 추가한 영화가 남음 | 추가한 영화를 등급에 놓고 ‘처음으로’를 누르니 추가한 영화가 완전히 사라졌음 | 보류 | 처음 영화 8개로 돌아가는 것이 기획서의 의도이며, AI 의견과 실제 결과가 다름 |
| AI: 빈 제목으로 추가하면 글자 없는 카드가 생김 | 영화 제목을 입력하지 않고 추가하니 하단에 빈 카드가 생성됨 | 반영 | 빈 카드는 영화를 분류하려는 목적에 맞지 않음 |
| 동료: 등급별 색이 달라 구분하기 쉬움 | 등급별 색깔이 있어 한눈에 구분하기 쉬웠음 | 보류 | 잘 작동하는 장점이므로 수정할 필요가 없음 |
| 동료: 상단의 영화 나눔 수가 유용함 | 상단 오른쪽에 나눔 결과가 표시되어 편했음 | 보류 | 잘 작동하는 장점이므로 유지하면 좋음 |
| 동료: 드래그 중 칸 색이 바뀌어 위치를 알기 쉬움 | 드래그앤드롭은 잘됐으나 드래그 중 배경색 변화는 따로 기록하지 못했음 | 되묻기 | 실제로 드래그 중 칸 색이 변하는지 다시 확인할 필요가 있음 |
| 동료: 휴대폰에서 사용하기 불편함 | 브라우저 화면을 좁히면 오른쪽 내용이 잘렸음. 휴대폰에서는 별도로 테스트하지 않았음 | 반영 | 기획서에는 화면 폭이 좁아져도 오른쪽이 잘리지 않아야 한다고 명시됨 |
| 동료: 카드 옮기는 방법이 처음에는 헷갈림 | 직접 사용할 때 드래그앤드롭은 잘됐음 | 되묻기 | 어떤 단계가 헷갈렸는지 구체적으로 물어보고 싶음 |
| 동료: 아래 영화 목록에서 위 S칸까지 드래그하기 불편함 | 드래그앤드롭은 잘됐으나 긴 거리 이동의 불편함은 별도로 확인하지 않았음 | 되묻기 | 실제로 이동 중 스크롤이 불편했는지 다시 확인하고, 동료에게는 어떤 배치가 편할지 물어보고 싶음 |
| 동료: 카드 색이 칙칙함 | 색감에 대한 불편은 직접 기록하지 않았음 | 보류 | 디자인 취향에 가까워 반드시 바꿔야 할 근거가 부족함 |
| 동료: 영화 포스터가 있으면 좋겠음 | 영화 카드에 이미지가 없어서 포스터가 있으면 좋겠다고 느꼈음 | 보류 | 개선 아이디어로는 좋지만 기획서의 필수 조건은 아니며, HTML 한 장으로 작동해야 하는 조건도 고려해야 함 |
| 동료: C등급은 없어도 될 것 같음 | S·A·B·C 등급으로 영화를 나눌 수 있었음 | 보류 | 기획서에서 C등급을 포함한 네 등급을 명시했음 |

- 아무도 말하지 않았는데 내가 찾은 것:
  - 브라우저 화면을 좁히면 오른쪽이 잘림. 기획서의 화면 폭 조건에 어긋나므로 개선 필요.
  - 영화를 입력한 뒤 추가 버튼을 클릭하지 않고 엔터만 눌러도 카드가 추가되어 편했음.
  - 영화 카드에 별점이나 삭제(X) 버튼이 있으면 개인적으로 더 편리할 것 같음. 다만 기획서의 필수 기능은 아님.
  - 등급 이름 옆의 카드 배치 영역에도 등급별로 연한 색을 적용하면 구분하기 좋을 것 같음.
  - 배경에 영화 관련 이미지를 넣는 아이디어도 있으나 필수 수정 사항은 아님.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:
  - AI는 ‘처음으로’를 눌러도 추가 영화가 남는다고 했지만 실제로는 사라졌음. AI 피드백도 직접 확인해야 한다는 점을 이야기하고 싶음.
