# 테스트 결과 보고

### 1. 잘된 점: 직접 사용해 보니 좋았던 부분
- 등급별로 색깔이 지정되어 있어서 한눈에 구분하기 가 쉬웠음
- 상단 오른쪽에 나눔에 대한 결과가 있어서 편했음
- 마우스 드래그드롭이 잘됐음
- 추가할 영화를 입력하고 마우스로 클릭안하고 바로 엔터만 셔도 추가 되서 편했음

### 2. 본 것: 어떤 기능을 사용했더니 어떤 문제가 있었는지
- 새로 고침했을때 자료가 남지 않았음
- 브라우져 화면이 작아지면 오른쪽이 잘림
- 내가 새로 추가한 영화를 등급에 올려놓고 처음으로 돌리면 하단에 남지 않고 완전히 사라짐
- 영화 제목을 적지 않고 추가 했을경우 하단에 빈페이지가 생성됨

### 3. 기준: 기획서 내용과 무엇이 다른지
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
  => 새로고침시 등급이 초기화됨
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
  => 오늘쪽이 잘림

### 4. 제안: 어떻게 고치면 좋을지
- 새로고침 했을 경우에 기록이 남아있엇으면 좋겠음
- 영화카드에 별표시가 있어서 재미를 체크할수 있게 햇으면 좋겠음
- 영화카드에 X 가 표시가 있어서 내가 지우고 싶을때 지울수 있엇으면 좋음
- 영화카드에 이미지가 있었으면 좋겠음
- 등급옆칸에도 색이 각각 있었으면 좋겠음
- 백그라운드에 영화관련 이미지가 들어가있었으면 좋겟음
